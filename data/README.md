# Data

This folder contains all datasets used in the project.  

- Keep **raw data** in a dedicated subfolder (`001_raw_data/`). 
- Store **processed or cleaned data** in another subfolder (`002_processed_data/`).  
- Always document the source of your data and any preprocessing steps you apply.  
- Do not upload datasets larger than 50 MB directly to GitHub (the limit is 100 MB). Use a `.gitignore` or external storage when needed.
- Keep your repo size under 1 GB.
